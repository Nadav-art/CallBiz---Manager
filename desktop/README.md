# CallBiz Desktop

שולחן עבודה לנציג — פרויקט עצמאי. קוד נפרד לחלוטין מהמנג׳ר;
נקודת המגע היחידה היא גשר ה-CRM (`js/crm-bridge.js`).

## שחרור גרסה חדשה
1. עדכנו את `window.APP_VERSION` ב-`index.html`.
2. עדכנו את `version.json` — `version`, `date`, `summary`, `notes`,
   ו-`critical: true` אם חובה לעדכן.
3. העלו את הקבצים. זהו.

הנציג יקבל באנר "יש גרסה חדשה" בהפעלה הבאה (ובדיקה חוזרת כל 15 דק׳
וכשחוזרים לחלון). לחיצה על "עדכן עכשיו" מנקה cache וטוענת מחדש.
בזמן שיחה פעילה העדכון ממתין לסיום השיחה.
